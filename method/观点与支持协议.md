# 观点与支持映射协议

先建立片段主线，再对改变理解的核心命题核查四项：
1. 声音：是谁在说？区分作者自己的建议、作者转引的观点、文中所描述的规则和你的解释。归属不明时不猜。
2. 命题：提出了什么，适用于谁、何种状态、时间与例外？不要因概括省掉会改变结论的条件。
3. 支持：给出的理由、引文与证据分别支持到哪一步？引文只能证明文内引用关系；不能自动证明来源真实、效果有效或数值充分。
4. 边界：原文是否在同一口径下存在未解释的张力？保留原表述与位置，不能换掉某个条件来替作者消解。你的可能解释必须与作者已证明的内容分开。

交付以读者理解为目的，不把论文改成审稿意见，不固定表格或文件数；只展示影响当前理解的映射。先给简洁主线，再说明关键选择如何推进、依据及必要的短引定位。缺项仅在影响当前解释时报告，不凭片段宣布全文没有。
