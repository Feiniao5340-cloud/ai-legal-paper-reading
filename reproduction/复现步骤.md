# 复现步骤

## 材料与环境

sources/case-A.txt：PDF8/刊119连续交强险讨论及三条脚注；case-B.txt：PDF7—8/刊118—119的风险责任与OTA段落；supplement-C.txt：仅用于核对平台分级责任原句。来源、DOI、转换及指纹见sources/provenance.json。仅必要片段，不提供全文与外部引文原件。

实际环境：Windows、Python3.12.14、Codex CLI0.166.0-alpha.5.1，请求gpt-6-luna/MAX。requirements.txt固定当前提取工具版本；已提供TXT的入口和find_quote只需标准库。模型后端权重及费用未知。

## 一 只准备输入，不调用模型

在仓库根目录执行：

```text
python -X utf8 reproduction/run_case.py --case A --variant baseline --out ../prepare-A --prepare-only
```

查看source.txt、SKILL.md、prompt.md及run_record.json。源指纹变化即停止，已有目录拒绝覆盖。此步无需账号或网络；本地转录已准备好，不再运行PDF提取。两臂都应用同一冻结Skill的语义要求。

## 二 完成阅读或对照

通过官方方式配置CLI和模型权限后执行：

```text
python -X utf8 reproduction/run_case.py --case A --variant baseline --out ../run-A-base --codex codex --model gpt-6-luna --reasoning max
python -X utf8 reproduction/run_case.py --case A --variant protocol --out ../run-A-method --codex codex --model gpt-6-luna --reasoning max
```

case改B即可复做第二案例。本轮顺序A基线/协议、B协议/基线。--codex可填实际路径；换模型或CLI选项须记录差异，不冒称同模型。输出目录分别全新。模型需账号和网络，程序不收集凭据。模型只解释标准输入，由程序保存回答，不把复制文件当阅读。

结果为answer.md、实际prompt.md、run_record.json和events.jsonl。退出0且存在回答只是技术完成，仍须核查含义。运行器不自动重试；错误、重连与超时保留。两臂自然任务逐字相同，变量仅附加协议，标准和旧结果不在模型输入中。不为“赢”减少基线材料或要求较弱答案。

## 三 检查结果与原句

自行读A1/A2或B1/B2，再对照evidence/本轮对照核查.md。核对来源、采用、支持与条件，不以字数或标签量打分。本轮无明确额外协议增益，默认导读后定点核查，协议作为备选。

无需模型的实际核字入口：

```text
python -X utf8 reproduction/find_quote.py --source sources/case-A.txt --quote 制度是否还有必要
python -X utf8 reproduction/find_quote.py --source sources/case-B.txt --quote 除非其能证明自己不存在过错
```

两者本轮实际命中。八项完整结果见evidence/机械核字结果.json。匹配仅作NFKC与空白归一，不作同义替换；未命中不证明全文没有，命中也不证明归属、法效或制度效果。

## 四 在玻尔复做

首页进入“文献阅读”，上传依法取得的同篇PDF，发送results/bohrium/context/首问输入.txt建立导读，按需发送context/首次追问输入.txt；真实历史回答同目录保留。

本轮依次发送method/玻尔核查输入.txt、method/玻尔定点复核输入.txt。它们在同一既有会话中执行，有前文提示，不是独立对照；模型未知，不保证逐字复现。完整文字、截图、采集说明见results/bohrium，核查见evidence/玻尔复核与最终阅读结论.md。

不要只要求“更严谨”而重写全文；先选具体疑点，核对承接、原句和注码。修正后逐项核对修改本身，保留原来正确的信息。第四答仍有过度纠正，不能直接当正确答案。

## 故障处理

找不到CLI则指定路径；无模型权限就记录失败，不用别的模型冒充。哈希变化先查版本，不绕过；已有目录换新目录，不删旧结果。策略拒绝工具时不扩大权限，本入口用本地程序提供已授权文本。网络错误保留原生事件，不只选最后成功结果。

本轮没有独立第三方复现、统计稳定性或容器科研执行。原生事件本地保留，公开完整提示词、回答和真实摘要。比赛外层传输只交付材料，不等于重做研究。
