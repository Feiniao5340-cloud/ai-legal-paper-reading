# 实操：从真实回答到可用导读

对象：[玻尔原始回答](../results/bohrium-new/model-output.txt)，同一篇论文E片段。以下是本会话AI回原文后的编辑处理，不是用户逐项标注、不是新模型回答，也没有覆盖原答。完整原检查见[核查记录](../evidence/玻尔新问答核查.md)。

## 第一步：先定读者问题，再看格式

这里需要理解作者选择哪种保险制度方向、怎样从争议走向建议。先读reader_markdown；证据卡用于核对有争议的归属。JSON齐全只能证明字段齐全，不能决定读者问题已解决。

## 第二步：把三类错误分开修

|实际原答问题（概述，不冒充逐字引语）|核对动作|可采用的编辑表述|为什么这样改|
|---|---|---|---|
|将作者另择方案说成不采纳市场萎缩、交强险难以为继的一方|对照A1的市场预测与“有鉴于此”之后的建议；检索不到“难以为继”|作者呈现市场萎缩预测，随后选择改造强制保险；本段未明确逐点否定该预测|事实预测与制度选择不处于同一判断层级；删掉源文没有的强结论|
|把作者接受被引观点写成接受比较优势与适配问题两层|分别找比较判断和过渡句，检查过渡究竟承接什么|能确认作者以适配不足推进修法建议；是否逐项接受替代方案比较判断，保持待查|态度必须指向具体命题，不能从局部承接扩成全盘接受|
|C5态度短引在句号与③之间漏掉结束引号|在A1逐字比对，并区分赔付功能引语与作者建议句|引用字段按原字符保留；态度依据改为作者“应当……增加强制保险”的建议，报道引语另作支持材料|先修引用边界，再修证据用途；只改标点不能完成语义复核|
|conditions补入L2—L3、投保主体定义与瑕疵标准等分析|逐项找段内是否明确提出这些条件|从“作者条件”中移出；需要讨论时另列为读者后续问题|合理延伸也不等于论文已写出的条件|

## 第三步：交付一份能读的结果

编辑后主件见[校订导读](校订导读.md)。它先用一句话给主题与制度方向，再分两条推进链，最后交代关键原句与阅读边界。读者不用先处理七张JSON卡，也能判断片段对自己的研究有何帮助。

复核者可按此顺序处理自己的论文：找到最终结论句；倒查结论前的转折或承接；把转引主语与作者态度分开；核对每个限定；最后压缩成导读。本文示例答案不要复制进新论文任务中充当所谓通用提示词。

## 第四步：验收分成两道关

机械关：离线重放应复现C5引文边界错误，而不是为了“全绿”修改原始回答。该结果只反映结构和短引。

语义关：回原文看改写是否仍越出作者表述，尤其是预测/主张、转引/采用、应然/实然。当前编辑是AI辅助、非盲复核，尚未取得新的独立读者验收。它不证明方法比基线更好，也不把修过的导读计入原实验成绩。

## 如何把经验迁移到另一篇文章

先选一段同时含争议观点与作者转折的原文，并附必要注释。沿[复现步骤](../reproduction/复现步骤.md)保留原输入输出，再按上表四列记录你实际发现的问题。若没有发现错误，直接记录没有发现，不为了演示凑错；若无法判断采用范围，保留待查，不让AI替作者补完整理论。
