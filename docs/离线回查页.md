# 十分钟操作：把导读与原文放在一起

无需账号、浏览器插件或第三方Python依赖。此工具解决实际操作问题：不用在JSON、Markdown与原文三个文件之间反复切换。它不提高模型准确率，也不替代读者判断。

## 1 先完整生成一个真实成功示例

在仓库根目录运行：

```text
python -X utf8 reproduction/review_page.py --source sources/case-D.txt --result results/D-map/model-output.txt --out ../review-D.html
```

用浏览器打开新生成的review-D.html：先读原模型导读，再逐卡看左右两栏。左侧为模型的归属/态度解释，右侧为指定段完整原文。D的三张卡检查无错误，但页面仍明确标注“关系待核”，而不是“理解正确”。生成页离线可用，没有网络请求或外部资源。

## 2 重现真实失败，而不是看一个全绿演示

```text
python -X utf8 reproduction/review_page.py --source sources/case-E.txt --result results/bohrium-new/model-output.txt --out ../review-bohrium.html
```

应生成页面并返回退出码2，显示C5的author_attitude短引未命中。它是遗漏引号的引用边界错误；不要把它夸大为整句虚构。即便其他锚点命中，也应回看C4的采用范围和主件的市场预测表述。逐项改法见[实际纠错](从错误到可用导读.md)。

## 3 接着核对尚未被程序发现的问题

把作者“选择改造强制保险”读成“否定市场萎缩预测”，是语义范围问题。页面只会展示模型解释和原文，不能自动替你判定。对应的校订表述见[校订导读](校订导读.md)，它由本会话AI非盲复核形成，不冒充原模型回答或新增读者验收。

## 4 用到自己的论文

先准备带[A1]等独立段号的必要原文和按method协议生成的JSON回答。运行时替换两个输入路径，输出必须是不存在的新.html。页面会完整转义模型文本；模型返回的HTML或脚本只显示为文字。段号无效时显示待查，不自动去其他段拼凑证据。原文件不会被改写。

本次已用D、E及玻尔真实结果做离线构建核查，并用含脚本标签的合成文本验证转义；这不是新增模型试验、浏览器视觉验收或独立用户可用性测试。原始实验与反例全保留。
