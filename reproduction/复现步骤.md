# 复现步骤

## 不调用模型先查看材料

从仓库根目录查看evidence/case-source.txt及reproduction/case-source-provenance.json。片段来自刘宏宇《我国自动驾驶汽车保险制度的立法审视与完善进路》，原刊2026年第3期112—122页；仅含必要片段，不能替代全文。

已有完整本地对照在examples/without-skill/answer-original.txt及examples/with-skill/answer-original.txt；玻尔两次实际回答在examples/bohrium；新增可运行案例在examples/self-contained。不要将三类结果混作同一实验。

## 准备环境

实际跑通环境为Windows、Python3.12.14、Codex CLI0.166.0-alpha.5.1，模型请求gpt-6-luna/MAX。当前机械环境使用python-docx1.2.0、pypdf6.10.0、pdfplumber0.11.9；requirements.txt固定这些本轮版本，不倒填为旧实验未记录的精确版本。模型后端权重、服务费用不可得。

在自己的独立环境安装requirements.txt，确保已通过官方方式配置Codex CLI和相应模型权限。本项目不读取或收集登录凭据，也无需把任何凭据放入仓库。其他CLI版本可能不支持这里的部分选项，应检查对应官方帮助并记录差异；不要随意删除安全设置。

## 第一步 检查准备结果

在仓库根目录执行：

```text
python -X utf8 reproduction/run_case.py --source evidence/case-source.txt --out ../reading-prepare --prepare-only
```

这一步只复制和提取材料，不调用模型。查看生成目录中的prompt.md、work/source/compact-fulltext.txt和run_record.json，确认片段边界、原页及P号。已有输出目录会被拒绝，换一个新目录，不删除旧结果。

## 第二步 完成真实阅读

```text
python -X utf8 reproduction/run_case.py --source evidence/case-source.txt --out ../reading-run --codex codex --model gpt-6-luna --reasoning max
```

若codex不在PATH，用实际可执行文件绝对路径替换第二个codex。模型调用需账号和网络，耗时及费用随环境变化。本案例默认inline模式：本地程序运行冻结提取脚本，再将完整Skill规则与源文通过标准输入提供给模型；模型不调用工具，程序保存回答。这与让Agent自行执行命令不同，记录中有delivery字段。

成功时查看answer.md、run_record.json、prompt.md和events.jsonl。进程退出0并不足以证明成功，脚本还要求存在实际回答；语义质量仍须按下一步人工核查。出错记录和stderr.log应保留，不用重写答案冒充运行成功。

## 第三步 判断结果是否可用

先核对不同等级责任主体与减免追偿，再核对车企留存自证、驾驶员配合及违规责任；检查模型是否区分一般赔偿与数据义务，是否把作者建议当现行法，定位是否实际存在。结果不必逐字相同。新的片段P号不是旧全文段号。

实际跑通结果和记录见examples/self-contained。evidence/自包含案例核查.md提供事前登记检查点及本轮依据；复现运行目录仅有材料与Skill，不把该核查文件、旧输出或评分表提供给执行模型。

## 故障处理

找不到CLI时传--codex；没有对应模型权限时记录错误并选自己有权限的模型，但不得称与本例同模型复现。遇到连接重连，保存错误、最终状态和使用量，不能据一次耗时比较效率。遇到策略拒绝文件读取，使用默认inline入口，不通过增大权限绕过限制。遇到源文提取失败，先检查prepare.stderr.txt及原件；这类失败在模型调用前停止。超时保留当前目录，下一次使用新目录，避免把部分输出覆盖为成功。

## 扩展到原全文或玻尔

原PDF指纹为9f5d6d638f6fdcb1e33b60d777a6c9b0874e24f1b9dec6d014a69c837a419d97，读者依法取得同版后可按原Skill流程准备正文。完整PDF大小、后附英文摘要和页码需核对；不能将本片段任务直接称作全文导读。inline示例设置120000字符输入保护上限，这不是对模型上下文容量的保证；超出时停止并明确缩小任务。

玻尔路径为首页进入文献阅读，上传同篇论文，发送界面适配提示词；发现具体疑点后使用追问输入并回原文核查。真实首问和追问分别保留，不跨平台、跨模型归因。机械提取核验、文字阅读复现与官方比赛评分是三件不同的事。
